# Day 2: Control Flow (Conditions, Loops, Logical Operators)

## Learning Objectives
1. `if`, `elif`, `else` conditionals (and indentation significance).
2. Logical operators: `and`, `or`, `not` (vs JS `&&`, `||`, `!`).
3. `while` loops vs `for` loops (`range()`, `enumerate()`).
4. Loop control: `break`, `continue`.

---

## Daily Task: Number Guessing Game (Without AI)
Build a script that:
1. Picks a secret target number (e.g. `secret = 42` or using `random.randint(1, 100)`).
2. Allows the user a maximum of 5 attempts (use a loop).
3. Tells the user if their guess is "Too high", "Too low", or "Correct!".
4. If correct, congratulates them, displays the number of attempts used, and breaks out early.
5. If attempts run out without guessing correctly, reveals the secret number.
