# Day 4: Data Structures (Lists, Tuples, Dictionaries, Sets)

## Learning Objectives
1. **List (`list`):** Ordered, mutable, indexed (`[1, 2, 3]`).
2. **Tuple (`tuple`):** Ordered, immutable (`(1, 2, 3)`).
3. **Dictionary (`dict`):** Key-value pairs, fast lookup (`{"key": "value"}`).
4. **Set (`set`):** Unordered, unique elements (`{1, 2, 3}`).
5. Time complexity intuition: $O(1)$ dictionary/set lookup vs $O(N)$ list search.
