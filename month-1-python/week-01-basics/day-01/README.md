# Day 1: Python Core Basics (Variables, Data Types, Input/Output)

## Learning Objectives
1. Python dynamic typing vs JavaScript (`let`, `const`).
2. Primitive data types: `int`, `float`, `str`, `bool`.
3. Type conversion (`int()`, `float()`, `str()`).
4. User input (`input()`) and formatted output (f-strings).
