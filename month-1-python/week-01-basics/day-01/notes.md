## 2. Professional Polished Version (For Tech Interviews)
> "In Python, variables do not require declaration keywords like `let` or `const`. Python dynamically infers the data type when a value is assigned. Unlike JavaScript, which enforces immutable bindings using `const`, Python does not have a native `const` keyword; developers indicate constant values by writing variable names in `ALL_CAPS` by convention."

---

## 3. Key Vocabulary Learned
- **Declare vs. Assign:** *Declare* means creating the variable; *Assign* means giving it a value.
- **Dynamic Typing:** The language detects the type automatically at runtime.
- **Convention:** A standard agreement among developers, not enforced by the compiler.
