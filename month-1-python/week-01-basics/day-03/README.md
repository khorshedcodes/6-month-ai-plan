# Day 3: Functions, Parameters, Return Values & Scope

## Learning Objectives
1. Function definition (`def`), arguments, and return values.
2. Positional vs. keyword arguments & default parameter values.
3. Variable scope (local vs. global).
4. Google-style docstrings for self-documenting code.

---

## Daily Task: Password Strength Validator (Without AI)
Build a modular script with clean helper functions:
1. `check_length(password, min_length=8)` -> returns bool
2. `has_digit(password)` -> returns bool
3. `has_uppercase(password)` -> returns bool
4. `evaluate_password(password)` -> calls helpers and returns strength score / message ("Weak", "Medium", "Strong").
5. Include a main loop asking the user for a password to evaluate.
