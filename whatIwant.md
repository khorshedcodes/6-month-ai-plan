# 4. How to stop AI from making you feel like you know something you don't

This is the part I care about most.

I want you to follow one rule:

Never accept code from AI that you cannot explain.

Use this learning method for every new concept.

## The 5-step learning method

1. Learn

   Read documentation or watch a lesson. Understand the concept.
2. Implement without AI

   Write a small implementation yourself. It's okay to make mistakes.
3. Use AI as a teacher

   Ask it to explain errors, question your understanding and review your code.
4. Rebuild from memory

   Close the tutorial and AI conversation. Recreate the implementation.
5. Explain it

   Write a short explanation of how it works, why you used it and what can go wrong.

For example, when learning linear regression:

Don't just import a library and run:

```
from sklearn.linear_model import LinearRegression
```

Understand:

1. What is the input?
2. What is the output?
3. What is the model trying to learn?
4. What are its parameters?
5. How does it measure error?
6. How does it improve its predictions?

Then use Scikit-learn.

You don't need to memorize every line of code. You need to understand what the code accomplishes.

## Your personal rule for AI usage

| Activity                          | AI allowed?       |
| --------------------------------- | ----------------- |
| Explaining concepts               | Yes               |
| Giving hints                      | Yes               |
| Debugging                         | Yes, after trying |
| Generating entire projects        | No                |
| Writing your first implementation | Prefer no         |
| Reviewing your implementation     | Yes               |
| Testing your understanding        | Yes               |

I'd also introduce a weekly closed-book test. If you cannot reproduce or explain something you supposedly learned last week, revisit it.
