# Lesson 3: Self-Introduction & Asking Time

## 1. Core Vocabulary

| Hanzi | Pinyin | Meaning | Tone Guide |
| :--- | :--- | :--- | :--- |
| **叫** | *jiào* | To be called / Name is | 4th (sharp falling) |
| **现在** | *xiànzài* | Now / Currently | 4th + 4th |
| **几点** | *jǐ diǎn* | What time? | 3rd (dipping) + 3rd |
| **了** | *le* | Particle (change of state) | Neutral |

---

## 2. Dialogue Practice:

### Introducing Your Name:
- **我叫 Khorshed。** (*Wǒ jiào Khorshed.*) = "My name is Khorshed."
- **我是工程师。** (*Wǒ shì gōngchéngshī.*) = "I am an engineer."

### Asking and Answering the Time:
- **问 (Question):** 现在几点了？ (*Xiànzài jǐ diǎn le?*) = "What time is it now?"
- **答 (Answer):** 现在三点了。 (*Xiànzài sān diǎn le.*) = "It is 3 o'clock now."
- **答 (Answer):** 现在七点了。 (*Xiànzài qī diǎn le.*) = "It is 7 o'clock now."
