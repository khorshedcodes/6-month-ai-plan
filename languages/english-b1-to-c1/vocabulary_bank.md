# C1 Professional Tech English Vocabulary Bank

> **Goal:** Transition from basic B1/B2 communication ("it was good", "I did this because fast") to **C1 Advanced Engineering Articulation**.

---

## 1. High-Signal Tech Transition Words (Replace "and then", "so")

| Instead of B1/B2... | Use C1 Advanced... | Real Engineering Context |
| :--- | :--- | :--- |
| "Because of this..." | **"Consequently, ..."** / **"Hence, ..."** | *"The API endpoint was deprecated; consequently, we migrated to v3."* |
| "On the other hand..." | **"In contrast, ..."** / **"Conversely, ..."** | *"Synchronous calls block execution; conversely, async coroutines yield control."* |
| "To make it faster..." | **"To optimize throughput..."** | *"We batched the requests to optimize throughput and mitigate latency."* |
| "Fix the problem" | **"Remediate the vulnerability / issue"** | *"We deployed an emergency patch to remediate the memory leak."* |
| "Make sure it works" | **"Ensure deterministic behavior"** | *"Unit tests ensure deterministic behavior across edge cases."* |

---

## 2. Professional Disagreement & Trade-off Framing
When in meetings or design reviews:
- *"While I acknowledge the simplicity of approach X, I believe approach Y offers superior scalability because..."*
- *"We are facing a fundamental trade-off between read latency and write consistency."*
- *"To mitigate potential points of failure, I suggest introducing an automated retry mechanism."*
